# BiG Lab 学習・研究参加ロードマップ

更新日: 2026-07-15  
期間: 面談前 〜 研究開始後12週間  
関連: [研究面談：予習・準備メモ](meeting-preparation.md)

## ゴール

12週間後までに、以下を達成する。

1. 角膜バイオエンジニアリングとコラーゲン系バイオインクの研究背景を、自分の言葉で5分説明できる
2. ラボの安全・倫理・データ管理ルールを守り、指導のもとで担当できる作業範囲を明確にする
3. 小さく再現可能な研究支援プロジェクトを1つ完了する
4. 結果を図、短いレポート、またはポスター形式で共有する
5. 次の研究テーマを、ラボの優先課題と自分の強みに基づいて提案できる

## 全体像

```text
面談前             Weeks 1–2          Weeks 3–4          Weeks 5–8           Weeks 9–12
理解と提案     →   オンボーディング  →  基礎と設計      →  小さな実装       →  発表と次の提案
論文・質問         安全・倫理           研究方法            データ/可視化        成果物・振り返り
```

> 原則: AI、マルチエージェント、3Dデザインは「研究の問いを明確にし、再現可能に伝えるための手段」。先に問い・データ・評価基準を決める。

- 研究論文の読み方: research question / method / outcome / limitation

### 実行タスク

- [ ] [2026年の二層バイオプリント角膜論文](https://pubmed.ncbi.nlm.nih.gov/41742708/)を読み、5点テンプレートで要約する

- [ ] `meeting-preparation.md` の質問を自分用に優先順へ並べ替える
- [ ] Yunong さんへ候補時間を2〜3枠送る
- [ ] A4一枚または3スライドの「Research fit & first pilot」を作る

### 面談での到達基準

- 最近の論文を1本、自分の言葉で1分説明できる
- 「何がまだ分からないか」を3つ質問できる
- 最初のプロジェクトを仮説ではなく、**小さく検証可能な作業**として提案できる

## Phase 1 — オンボーディングと研究の土台（Weeks 1–2）

### 目的

ラボの優先課題、自分の役割、扱ってよいデータ・作業を明確にする。

### 学ぶこと

- 研究倫理、患者情報・未公開データの取り扱い
- データ管理: ファイル命名、版管理、出典、バックアップ、アクセス権
- 実験計画の基本: 問い、仮説、対照、評価指標、再現性
- ラボ固有の安全・機器・実験トレーニング（必要な場合のみ、必ず指導者のもとで）

### 実行タスク

- [ ] 指導者と「最初の4週間で出す成果物」を一文で合意する
- [ ] 研究ノートのテンプレートを作る
- [ ] データ／文献の使用範囲を確認し、書面またはメモに残す
- [ ] 各タスクの担当者・レビュー担当者・締切を決める
- [ ] 週1回、10〜15分の進捗共有方法を決める

### 成果物

- `project-charter.md` — 目的、範囲外、成果物、期限、レビュー方法
- `data-and-ethics-notes.md` — 利用可否、保管場所、引用・承認ルール
- `research-log.md` — 日付、作業、判断、質問、次の一手

### 次へ進む判断基準

- 研究の問いと成果物が指導者に確認されている
- 患者データ・未公開データを扱う必要性と権限が明確である
- 「何をしないか」が書かれている

## Phase 2 — 分野基礎とプロジェクト設計（Weeks 3–4）

### 目的

医学・材料・データの用語をつなぎ、プロジェクトの評価方法を設計する。

### 学ぶこと

#### Biomedical foundations

- 角膜の層構造と透明性・機械特性・細胞生存性の関係
- コラーゲン I / IV と、角膜組織工学での役割
- 3D bioprinting の基本的な流れ: material → printing → culture / evaluation
- 研究で使われる評価指標と、その解釈上の限界

#### Research foundations

- 文献検索と引用管理
- systematic review と narrative review の違い
- データ辞書、欠損値、単位、メタデータ、データ来歴（provenance）
- 図表の読み方: 軸、単位、サンプル数、対照、エラーバー、限界

### 実行タスク

- [ ] 3〜5本の論文を同じテンプレートで比較する
- [ ] 用語集を30語程度作る（日英対照で可）
- [ ] 「問い → 入力データ → 処理 → 評価指標 → 図」の流れを1枚に描く
- [ ] 指導者と、使う評価指標・対象データ・除外条件を確認する

### 成果物

- `literature-matrix.csv` または Markdown表
- `glossary.md`
- `research-workflow-diagram.md` または1枚の図

### 次へ進む判断基準

- 選んだテーマの背景、方法、限界を2分で説明できる
- 可視化したいデータ項目と単位が定義されている
- 指導者が「この小さな範囲なら始めてよい」と確認している

## Phase 3 — 再現可能なデータ・可視化スキル（Weeks 5–6）

### 目的

研究用データを安全に整え、第三者が追える図を作れるようにする。

### 学ぶこと

- CSV / Excel の構造、tidy data、データ検証
- Python（`pandas`、`matplotlib` または `seaborn`）または R の基礎
- Git または版管理の基本（未公開データはラボのルールに従う）
- 可視化の原則: 比較、色、ラベル、単位、注釈、アクセシビリティ
- notebook / script の再現性: 入力、処理、出力、環境を分ける

### 実行タスク

- [ ] 公開データまたは承認済みのサンプルデータで、データ辞書を作る
- [ ] 読み込み・検証・整形・図の生成を1つの再実行可能な手順にする
- [ ] 図を最低3種類試し、最も研究の問いに答える1つを選ぶ
- [ ] 指導者に「この図から言ってよいこと／言ってはいけないこと」を確認する

### 成果物

- `data_dictionary.md`
- `analysis.ipynb` または `analysis.Rmd`
- `figure-v1.png` と図のキャプション
- `reproducibility-notes.md`

### 次へ進む判断基準

- 元データから図を再生成できる
- 図の各軸、単位、集計方法、除外条件を説明できる
- 研究上の結論と探索的な観察を区別できる

## 週あたりの学習配分（目安）

ラボから指定された時間・トレーニングを最優先にし、それ以外は次の比率を目安にする。

| 領域 | 目安 | 内容 |
| --- | ---: | --- |
| 分野理解 | 2時間 | 論文、用語、背景知識 |
| 研究スキル | 1時間 | 文献管理、倫理、実験・分析設計 |
| データ / 可視化 | 2時間 | Python/R、整形、図、再現性 |
| 共有と振り返り | 30分 | 研究ログ、質問、次週計画 |

最初の1〜2か月は、週5〜6時間の自己学習を上限の目安にする。wet lab のトレーニングやプロジェクト時間が始まった場合は、自己学習を減らしてラボの実務・安全教育を優先する。

## 学ぶ順番の判断ルール

| 状況 | 優先すること |
| --- | --- |
| ラボが wet lab 作業を依頼した | 安全、手順、実験記録、指導者のトレーニング |
| 公開データ／実験メタデータを扱う | データ辞書、品質確認、再現可能な可視化 |
| 患者データを扱う可能性がある | 倫理、アクセス権、匿名化、保管ルールを先に確認 |
| 文献整理が課題になった | 検索式、出典、比較表、引用管理 |
| ポスターや説明資料が必要になった | 研究の問い・結果を先に確定し、3Dやデザインは最後に使う |

## 最低限の習慣

- 毎回の作業後、`research-log.md` に「行ったこと・分かったこと・不明点・次の一手」を4行で残す
- 週に一度、指導者に聞く質問を3つ以下に絞る
- 図や表には、出典・作成日・データ版・単位を必ず記載する
- AIを使った作業は、最終判断を人間が確認したことを残す
- 未公開情報は個人の公開GitHub、外部AI、個人クラウドに置かない

## 12週間後の分岐

最初の成果物を完成させたら、ラボの需要と自分の興味に応じて、次のどちらかへ進む。

### A. Computational / visualisation track

- 文献・実験データの比較基盤を育てる
- 画像・表形式データの品質管理と解析を学ぶ
- ケラトコーヌスなどのAI研究では、評価・バイアス・説明可能性を重点的に学ぶ

### B. Wet-lab / bioengineering track

- ラボ認定の安全・実験トレーニングを段階的に受ける
- コラーゲン、細胞培養、3Dプリント、評価法のいずれか一つに焦点を絞る
- 実験計画、再現性、観察記録、結果の可視化を一体で学ぶ

両方を同時に深く進めようとせず、最初の3か月は主軸を1つ選ぶ。
