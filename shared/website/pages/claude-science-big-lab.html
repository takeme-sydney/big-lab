Pilot charter

Curved Corneal Construct QC。

CAD、校正済み写真、surface scan、OCTのうち利用可能な入力から、一つのprimary metricを安定して再生成できる状態を目指します。

RESEARCH NEED
手作業で時間がかかるconstruct評価を、sample IDで追跡できるQCへ変える。
INPUT
承認済みのCAD、写真、scan、OCT、manual referenceのいずれか。
PRIMARY METRIC
曲率、厚さ、表面偏差、収縮率、layer continuityから一つ選ぶ。
OUTPUT
QC overlay、metrics.csv、method.md、failure log、再実行script。
VALIDATION
手動referenceとの誤差、bias、再現性、失敗する画像条件を示す。
BOUNDARY
通常写真だけから透過率、haze、屈折率などの光学性能を主張しない。

Four-week plan

理解から、再実行できる成果へ。

WEEK 01

問いとデータを固定

  • manual bottleneckを確認
  • experimental unitを定義
  • metricを一つ選ぶ
  • charterとdata dictionaryを承認
WEEK 02

最小baselineを作る

  • raw data loader
  • calibration / segmentation
  • sampleごとのoverlay
  • metric・unit・QC flagを保存
WEEK 03

手動評価と比較

  • reference subsetと比較
  • 誤差・bias・再現性
  • 失敗条件を分類
  • scriptを再実行
WEEK 04

研究判断へ渡す

  • rawから図とCSVを再生成
  • 方法・結果・限界
  • 5分demo
  • 次の候補は最大2つ

Project structure

rawとoutputを物理的に分ける。

Claude Scienceにはinputをread-only、outputだけをread & writeで許可します。sample IDをfile名と表の両方に残します。

corneal-qc/ ├── 00_charter/ │ ├── research_question.md │ └── data_dictionary.csv ├── 01_raw/ # READ ONLY │ ├── images/ │ ├── scans/ │ └── cad/ ├── 02_reference/ │ └── manual_measurements.csv ├── 03_output/ # READ & WRITE │ ├── qc_overlays/ │ ├── tables/ │ └── figures/ ├── 04_code/ └── README.md

First session

最初の依頼を具体化する。

利用できる入力とmetricが未確定なら、解析を始めさせず、候補と必要条件を比較させます。

@[corneal-qc]を確認してください。 目的: 曲面角膜constructの[primary metric]を、 sample IDで追跡できるQCとして再生成可能にする。 制約: - 01_rawはread-only - experimental unitはconstruct - calibrationと単位を必ず記録 - 全sampleのoverlayを保存 - manual referenceとの差を評価 - failure conditionを除外せず分類 - 写真から測れない光学特性は主張しない まずコードを実行せず、 入力確認、最小Plan、必要権限、Artifact、 validation方法を提示してください。

Measurement boundary

入力に合わせて、言えることを制限する。

入力測定候補主な限界
校正scale付き写真直径、輪郭、投影面積、高さ、簡易曲率、収縮3D表面全体と光学特性は測れない
複数角度写真 / surface scan3D再構築、target mesh registration、偏差map透明・湿潤試料は反射と輪郭が不安定
OCT / confocal z-stack厚さ、前後面、層境界、局所曲率装置calibrationと専門家の解釈が必要
Microscopy画像viability、coverage、cell density、alignmentsegmentation誤差とfield selectionを確認
「透明に見える」と「光学性能が高い」は別。

通常写真は固定条件下の相対QCには使えても、透過率、haze、屈折率を直接主張する根拠にはなりません。

Definition of done

完成は、精度だけで決めない。

Traceable

必須
Re-runnable

必須
Validated

manual referenceとの差、bias、再現性を示す。

必須
Bounded

適用範囲、失敗条件、言えないことを明記する。

必須
Approved

データ利用、成果共有、次の実験判断を担当者が承認する。
