Before install

最初に4項目だけ確認。

条件を満たさない場合、インストール後のsign inやruntime構築で止まります。

Claude accountPro / Max / Team / Enterprise。Free planは対象外。
macOSmacOS 13以降。Apple SiliconまたはIntel。
Linuxx64、glibc、bubblewrap 0.8.0+、socat、user namespace。
Storageruntimeとstarter Python / R環境に約5 GB。
Team / Enterpriseは管理者の有効化が先。

OwnerまたはPrimary OwnerがOrganization settings → CapabilitiesからClaude Scienceをonにします。API keyは不要です。

Install

使う環境を選ぶ。

タブを切り替えて手順を確認してください。ブラウザに画面が開きますが、Claude Scienceはローカルアプリです。

macOSで始める

  1. 公式ダウンロードページを開く。
  2. Apple menu → About This MacでChipを確認し、Apple SiliconまたはIntel版を選ぶ。
  3. installerを開く。初回のPython / R環境構築が終わるまで待つ。
  4. 既定browserでClaude accountへsign inする。

Linuxで始める

Ubuntu / Debianでは先にsandbox依存関係を入れます。Ubuntu 22.04標準のbubblewrapは必要versionより古いため注意してください。

sudo apt-get update && sudo apt-get install -y curl bubblewrap socat
curl -fsSL https://claude.ai/install-claude-science.sh | bash claude-science serve

表示されたlocal URLを同じmachineのbrowserで開きます。Remote serverではSSH tunnelを使います。

組織で有効化する

  1. Organization settings → Capabilitiesを開く。
  2. Claude Scienceのtoggleをonにする。
  3. setup wizardでrole accessとConnectorを確認する。
  4. Enterpriseのcustom roleにはClaude Science capabilityを追加する。

HIPAA注意： 組織で有効化できても、Beta中のClaude Science利用はBAA対象外です。PHIを扱わないでください。

First analysis

最小の解析を8ステップで。

目的は立派な結果を出すことではなく、権限・実行・保存・検証の流れを理解することです。

Sign inとsetup wizardを完了

Connector、Skill、アクセス可能なwebsiteは後からSettingsで変更できます。

練習用Projectを作成

一つの研究テーマを一つのProjectにします。Projectは関連SessionとArtifactをまとめます。

Project instructionsを記入

目的、experimental unit、単位、除外基準、出力形式、禁止事項を短く書きます。

入力folderを指定

composerでpathを入力するか、@ pickerから選びます。添付fileはアプリのlocal data folderへcopyされます。

まずread-onlyで許可

raw dataを上書きしないよう、入力と出力のfolderを分けます。

Planを確認して承認

入力、手法、仮定、QC、成果物、failure modeを読んでから実行へ進みます。

Code permissionを確認

実行するlanguage、command、package install、network accessが目的と合うかを見ます。

ArtifactとProvenanceを開く

Filesから成果物を開き、Messages、Code、Execution Log、Environment、Reviewを確認します。

DONE → provenance付きArtifactが1つ保存された

First-launch help

起動で止まったとき。

macOSでアプリに禁止マークが出る

Macのprocessorと異なるbuildを選んだ可能性があります。About This MacでChipを確認し、Apple SiliconまたはIntel版を再downloadします。

browser tabが開かない

macOSはmenu bar iconからOpen。Linuxはterminalのlocal URLを開くか、claude-science urlで新しいURLを表示します。

Linuxで起動しない

bwrap --versionで0.8.0以上を確認し、socatとunprivileged user namespaceが利用できるか確認します。

sign inがclaude.aiで止まる

Free plan、OAuth redirect、組織で未enableのいずれかを確認します。SSH tunnelではPaste a codeを使えます。
