034-WEEK PILOT

Small scope / review every week

アプリ完成を目指さない。
判断可能な一周を作る。

一つのconstruct type、一つのprimary metric、既存の承認済みデータに限定。各週の出口に人間のacceptance gateを置きます。

  1. WEEK 01DEFINE

    問い・単位・許可を固定

    sample hierarchy、target、tolerance、manual reference、データ利用範囲を確認。

    • Pilot charter
    • Data dictionary
    • Permission record
    HUMAN GATEMetric definition approved
  2. WEEK 02BUILD

    baselineとtestを実装

    loader、校正、registration、radius測定、既知値test、全sampleのQC flag。

    • Code + config
    • Unit tests
    • Overlay set
    HUMAN GATEMethod + failure reviewed
  3. WEEK 03COMPARE

    設計と実測を比較

    radius deviation、thickness、surface RMSEをbatch・sample単位で可視化。

    • 3D deviation map
    • QC dashboard
    • Failure registry
    HUMAN GATEQC state assigned
  4. WEEK 04COMMUNICATE

    結果・限界・次を一枚に

    同じvalidated outputからfigure、caption、review poster、次実験案を生成。

    • Poster / PDF
    • Claim map
    • Re-run guide
    HUMAN GATEClaims + sharing approved

07SAFETY BOUNDARY

Automation is conditional

AIに任せる実行と、
人間が担う科学的判断。

安全境界は「AIを使う／使わない」ではなく、どの判断に誰の承認が必要かを成果物ごとに固定します。
