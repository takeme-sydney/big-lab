One translational system

仕事は、
治療までつながる。

BIGの公開研究は、材料だけ、AIだけで完結しない。臨床課題から材料・細胞・造形・評価・事業化までを往復する。18の役割は、この5段階を動かすために必要になる。

01 / NEED

臨床課題

角膜疾患、組織損傷、患者負担、ドナー不足を定義する。

02 / DESIGN

材料・細胞

collagen、bioink、protein、細胞、drug deliveryを設計する。

03 / MAKE

造形・デバイス

3D bioprinting、FixStem、microfluidics、製造条件を形にする。

04 / PROVE

評価・データ

形状、透明性、力学、細胞、安全性、再現性を検証する。

05 / TRANSLATE

臨床・製品化

共同研究、IP、規制、製造、spin-off、社会実装へ運ぶ。

SENIOR EXPERT ROLE

Recommended first contribution

Curved Corneal
Geometry QC.

最初から大規模AIを作らない。承認済みの既存画像・OCT・scanのいずれかを使い、1種類のconstruct、1〜2指標だけを再現可能に測る。

設計値に対する radius error または local thickness error を、sample → print run → bioink batch → method version まで追跡できる形で出せるか。
WHY TAKUMI

3つの強みが同時に使える

Medical Scienceで問いを理解し、Python / product engineeringで処理を再実行可能にし、3D / Visual Artsで誤差を人間が検証できる形にする。

DELIVERABLES

見せるのはアプリではなく証拠

data dictionary、manual reference、overlay、metric CSV、failure log、versioned code、1ページreport。

SUCCESS

別の人が再生成できる

raw dataを変更せず、校正・除外・単位・限界を残し、研究者が原データと照合できること。

WEEK 01 / SCOPE

問いとデータを固定

primary metric、experimental unit、利用許可、design reference、reviewerを合意。

WEEK 02 / BASELINE

手動値を再現

1〜2例でloader、calibration、manual reference、QC overlayを作る。

WEEK 03 / VERIFY

失敗例まで比較

小規模setに適用し、blur、欠損、segmentation failureを隠さず分類。

WEEK 04 / HANDOFF

判断に使える形へ

コード、table、figure、method、limitation、次実験案を研究者レビューへ。

Safety & credibility

できることより、
境界が重要。

Takumiの強みは横断性だが、横断性は専門家判断を代替しない。研究データ、細胞、安全性、臨床主張、著者資格、IPは、必ずラボの承認とレビューの中で扱う。

今すぐ提案してよい

  • 公開文献のevidence matrixと用語・測定taxonomy
  • 承認済み画像／装置出力のQC・可視化pilot
  • sample・run・batchを結ぶexperiment registry
  • 再実行可能な図、method、README、research log
  • ポスター、graphical abstract、一般向け研究説明

独力で担当しない

  • 正式訓練なしの細胞培養、bioink調製、機器操作
  • 角膜・疾患・患者データの臨床的診断や有効性判断
  • 小規模データからの高度AI・因果・一般化性能の主張
  • 未公開データを個人GitHubや外部AIへ送ること
  • 倫理、規制、著者資格、IPを自分だけで決めること
