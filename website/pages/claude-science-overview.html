名称を先に整理

正式名称は「Claude Science」です。「Claude Code Science」という製品名ではありません。Claude Codeはソフトウェア開発、Claude Scienceは再現可能な科学解析を中心にした別のアプリです。

What it is

問いを、検証できる成果物にする。

自然言語で研究課題を伝えると、Claudeが計画を作り、許可を求め、Python・R・shellを実行し、図・表・処理済みデータ・原稿を由来情報と一緒に保存します。

文献、コード、科学データベース、計算環境、図、原稿を、一つのProjectでつなぐ研究作業台。

一般的なチャットAIと違い、実際にコードを実行できます。一般的なNotebookと違い、会話から専門エージェント、Connector、Skill、HPCまでを調整します。すべてを置き換える製品ではなく、研究室が既に使う道具をつなぐ場所です。

How a result is made

成果物までの5つの場所。

研究者が責任を持つ判断と、Claudeへ任せる実行を混ぜないことが、安全で再現可能な使い方の基本です。

01 / YOU

研究の問い

目的、experimental unit、primary outcome、制約を決める。

02 / PLAN

計画と権限

Claudeの手順、仮定、必要なfolder・network・computeを確認。

03 / EXECUTE

解析を実行

専門SkillとConnectorを選び、sandboxでコードを実行。

04 / ARTIFACT

成果物を保存

図、表、script、reportをversionつきで保存。

05 / VERIFY

記録と照合

Reviewerと人間が主張、実行記録、研究妥当性を確認。

Choose the right surface

Claude、Code、Scienceの違い。

同じClaude系でも、主な作業場所と保存する成果が違います。

製品主な作業場所向いている仕事研究での使いどころ
ClaudeWeb / Desktop / Mobile 会話と文書 質問、要約、執筆、Research アイデア整理、文献の理解、文章レビュー
Claude CodeTerminal / IDE / Web コードリポジトリ 実装、テスト、デバッグ、Git 解析パイプラインや研究ソフトの開発
Claude ScienceLocal app / Browser UI 研究Projectと計算環境 RECOMMENDED 文献＋データ＋計算＋図 実データ解析、由来記録、科学ツール連携

Know the boundary

便利さと、保証を分ける。

Reviewerは最終保証ではない

ReviewerはClaudeの主張と実行記録を照合しますが、解析を再実行せず、研究手法が問いに適切かを保証しません。臨床・診断用途の製品でもありません。重要な結果は研究者が原データと別手段で確認します。
