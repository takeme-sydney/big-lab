00POSITION

The central idea

強みは「作れること」ではなく、
研究のボトルネックを外せること。

BiG Labでの価値

角膜construct、3D bioprinting、biomaterial、画像・測定データの間をつなぎ、研究者が比較・検証・共有しやすい成果物へ変換する。

名称の整理

Claude Codeは解析実装、Claude Scienceは研究Project・実行・由来管理を担う別の環境です。このページでは二つを「AI Research Ops」として連携させます。

05START SMALL

Recommended first pilot

最初は4週間。
一つのconstruct、
一つのmetric。

PILOT QUESTION

既存の角膜construct画像／3D dataから、承認済みの一つの形状指標を再現可能に測り、研究者が判断できる一枚のQC posterにできるか？

  1. W1
    DEFINE

    問いとデータを固定

    利用許可、sample階層、metric、manual reference、成功条件を確認。

    CHARTER
  2. W2
    BUILD

    baselineを実装

    loader、校正、測定、test、全sampleのoverlayとQC flag。

    CODE + TEST
  3. W3
    COMPARE

    3Dとdataで比較

    設計値／手動値との差、ばらつき、failure modeを可視化。

    FIGURE SET
  4. W4
    COMMUNICATE

    一枚でレビュー

    方法、結果、限界、次の実験をposter形式へまとめ、研究者が検証。
